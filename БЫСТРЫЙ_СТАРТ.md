## 🔧 Установка и запуск (10 минут)

### Шаг 1: Установить зависимости

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### Шаг 2: Настроить переменные окружения

**Backend** (`backend/.env`):
```bash
cd backend
cp .env.example .env
```

Отредактируйте `.env` и добавьте:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
JWT_SECRET=любая_длинная_случайная_строка_32_символа
NODE_ENV=development
```

**Как получить токен бота:**
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте токен (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

**Как сгенерировать JWT_SECRET:**
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

**Frontend** (`frontend/.env`):
```bash
cd frontend
cp .env.example .env
# Для локальной разработки можно оставить как есть
```

### Шаг 3: Запустить серверы

**Терминал 1 - Backend:**
```bash
cd backend
npm start
```
Должно появиться: `🚀 Server running on http://localhost:3001`

**Терминал 2 - Frontend:**
```bash
cd frontend
npm run dev
```
Должно появиться: `Local: http://localhost:5173`

### Шаг 4: Проверить что работает

Откройте в браузере: http://localhost:5173

✅ Должна загрузиться главная страница
✅ Видны категории и товары
✅ Поиск работает

**Админ панель:** http://localhost:5173/#/admin

- Кликните "Использовать пароль"
- Логин: `admin`
- Пароль: `admin`

## 📱 Тестирование в Telegram (локально)

Для тестирования в Telegram используйте ngrok:

```bash
# Установить ngrok
npm install -g ngrok

# Запустить серверы (2 терминала как выше)

# Терминал 3: Открыть backend
ngrok http 3001
# Скопировать HTTPS URL (например https://abc123.ngrok.io)

# Обновить frontend/.env
echo "VITE_API_URL=https://abc123.ngrok.io/api" > frontend/.env

# Перезапустить frontend
cd frontend && npm run dev

# Терминал 4: Открыть frontend  
ngrok http 5173
# Скопировать HTTPS URL (например https://def456.ngrok.io)
```

**Настроить бота:**
1. Откройте @BotFather в Telegram
2. Отправьте `/setdomain`
3. Выберите вашего бота
4. Введите: `def456.ngrok.io` (без https://)
5. Отправьте `/setmenubutton`
6. Выберите бота
7. Текст кнопки: `Открыть магазин`
8. URL: `https://def456.ngrok.io`

Теперь откройте бота в Telegram и нажмите кнопку меню!

## 🚀 Деплой в продакшн (30 минут)

### Backend на Railway

1. Зайдите на [railway.app](https://railway.app)
2. New Project → Deploy from GitHub repo
3. Выберите ваш репозиторий
4. Root Directory: `backend`
5. Environment Variables:
   ```
   PORT=3001
   NODE_ENV=production
   TELEGRAM_BOT_TOKEN=ваш_токен
   JWT_SECRET=сгенерированный_секрет
   FRONTEND_URL=https://ваш-сайт.vercel.app
   ```
6. Deploy

Скопируйте URL backend (например `https://ваш-backend.up.railway.app`)

### Frontend на Vercel

1. Зайдите на [vercel.com](https://vercel.com)
2. New Project → Import Git Repository
3. Root Directory: `frontend`
4. Environment Variables:
   ```
   VITE_API_URL=https://ваш-backend.up.railway.app/api
   ```
5. Deploy

Скопируйте URL frontend (например `https://ваш-сайт.vercel.app`)

### Обновить бота

```

→ ваш-сайт.vercel.app

/setmenubutton
→ Открыть магазин
→ https://ваш-сайт.vercel.app
```

## 👤 Как стать администратором

По умолчанию все пользователи Telegram имеют роль `user`.

Чтобы получить права админа:

1. Откройте бота в Telegram
2. Зайдите в админ панель (автоматически залогинитесь)
3. Запишите ваш Telegram ID (показан в админке)
4. Подключитесь к базе данных Railway
5. Выполните SQL:

```sql
-- Найти вашего пользователя
SELECT * FROM telegram_users WHERE telegram_id = 'ВАШ_TELEGRAM_ID';

-- Сделать админом
UPDATE telegram_users SET role = 'admin' WHERE telegram_id = 'ВАШ_TELEGRAM_ID';

-- Или главным админом
UPDATE telegram_users SET role = 'master_admin' WHERE telegram_id = 'ВАШ_TELEGRAM_ID';
```

Перезайдите в админ панель - теперь у вас есть доступ!

## 🔐 Безопасность

✅ **Telegram аутентификация** - Официальная валидация HMAC SHA-256
✅ **JWT токены** - Защищенные сессии с истечением через 7 дней
✅ **Bcrypt** - Хеширование паролей
✅ **Rate limiting** - Защита от перебора (100 req/15min)
✅ **Helmet** - Защитные заголовки (XSS, CSP и т.д.)
✅ **CORS** - Ограничен только вашим доменом
✅ **SQL injection** - Защита через prepared statements

## ❓ Проблемы?

### Backend не запускается
```bash
cd backend
rm -rf node_modules package-lock.json
npm install
npm start
```

### Frontend не запускается
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### CORS ошибка
Проверьте что `FRONTEND_URL` в backend/.env совпадает с вашим фронтенд доменом.

### Не работает аутентификация Telegram
Убедитесь что `TELEGRAM_BOT_TOKEN` в backend/.env правильный.

### База данных пустая
Удалите `backend/database.sqlite` и перезапустите backend - создадутся тестовые данные.
